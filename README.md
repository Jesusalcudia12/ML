Este bot inteligente está diseñado para rastrear precios de productos en **Mercado Libre México**. Cuando detecta una baja de precio o alcanza una "meta" establecida, envía automáticamente una alerta visual a un canal de Telegram con el link de afiliado.

---

## ✨ Características Principales

* 🤖 **Automatización Total:** Monitorea precios cada 15 minutos (configurable).
* 📉 **Detección Inteligente:** Avisa si el precio baja, incluso si no ha llegado a la meta ideal.
* 📦 **Carga Masiva:** Permite agregar listas de productos mediante un solo comando.
* 🔒 **Seguridad Reforzada:** Solo el administrador configurado puede controlar el bot.
* 🖼️ **Alertas Visuales:** Envía imagen del producto, descripción y botón de compra directa.
